# @workbench/mobile

The Tauri Android client for Workbench server mode. It connects to a
`workbench-server` (or a desktop in server mode) over `HttpTransport` and gives
a chat-first home screen plus Claude/Codex chats and server terminals.

See [`docs/MOBILE.md`](../../docs/MOBILE.md) for pairing, saved machines, the
in-app updater and chat.
