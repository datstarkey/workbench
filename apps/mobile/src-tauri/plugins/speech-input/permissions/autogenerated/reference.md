## Default Permission

Allows opening Android speech input to dictate a chat draft.

#### This default permission set includes the following:

- `allow-recognize`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`speech-input:allow-recognize`

</td>
<td>

Enables the recognize command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`speech-input:deny-recognize`

</td>
<td>

</td>
</tr>
</table>
