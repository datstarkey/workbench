# Release v0.19.0

**Released:** 2026-06-02
**Previous version:** v0.18.2

This release introduces the Workbench Pro visual redesign — a denser, more polished slate interface with selectable accent themes and refreshed window chrome — alongside a more flexible GitHub merge experience that lets you choose how pull requests get merged.

## New Features

- **Workbench Pro redesign** — a refreshed, denser slate interface throughout. New 44px activity rail and 22px status bar, restyled sidebar with nested worktrees and session badges, refreshed workspace and terminal tabs, a welcome hero on the empty state, and a redesigned settings modal. Pick your accent color (violet, tideline, ember, moss, or iris) from the new Appearance settings. (#64)
- **Flexible pull request merging** — the merge button is now a split dropdown: choose your merge method (squash, merge commit, or rebase), toggle delete-branch and admin override, or enable auto-merge so a PR merges automatically once checks pass. (#63)
