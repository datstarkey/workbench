# Release v0.24.0

**Released:** 2026-06-04
**Previous version:** v0.23.1

This release refines the workspace and terminal tab strips with cleaner, auto-hiding scrollbars that no longer steal layout space.

## Improvements
- Tab strips now use auto-hiding overlay scrollbars instead of always-on native ones. Scrollbars float over the tabs and stay out of the way until you scroll, so the tab strip keeps its full width and looks cleaner. Styling matches the app's chrome theme. (#78)
