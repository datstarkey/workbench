# Release v0.20.0

**Released:** 2026-06-02
**Previous version:** v0.19.0

This release makes the Settings window a proper floating panel you can move and size to taste, and fixes a frustrating double-click bug introduced with the Workbench Pro redesign.

## New Features

- The Settings window can now be **dragged** by its title bar and **resized** from the bottom-right corner. Your chosen position and size are remembered and restored the next time you open Settings (#66)

## Bug Fixes

- Fixed controls across the toolbar, tabs, and sidebar requiring **two clicks** to respond — a single click now works everywhere again (#65)
- Restyled the right sidebar (GitHub / Boards / Git) to match the Workbench Pro chrome it was previously missing (#65)
